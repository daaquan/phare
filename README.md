# Phox

Phoxは、高速かつ直感的なWebアプリケーション開発のためのPhalcon PHPフレームワークに基づいたフレームワークです。

## 主要特徴

- 高速な実行速度
- 簡易なルーティング
- サービスコンテナーと依存注入
- 柔軟なORM
