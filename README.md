# API Skeleton

## Get Started

### Requirements

To run this application on your machine, you need at least:

* PHP >= 8.1
* Phalcon >= 5.0
* MySQL >= 8.0
* Nginx Web Server

### Install via composer create-project

```bash
composer create-project g/skeleton /path/to/app-folder "dev-master" --prefer-dist  path --repository-url=http://10.2.2.84:10080
```

### Installing Dependencies via Composer

```bash
cd app-folder
composer install
```
